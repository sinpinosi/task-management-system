# Windows Local Taskflow (タスク管理システム)

## 概要
このシステムは、Windowsのローカル環境で動作し、追加インストール不要（Node.jsやPythonなどの環境構築不要）で使える完全ローカル向けのGUIタスク管理ツールです。
各タスクデータや設定したテンプレートはJSONファイルとして出力・管理されるため、ファイルサーバ（共有フォルダ）などを保存先に指定することで、簡易的に複数人での情報共有が可能です。

---

## 動作環境・システム要件
- **OS**: Windows 10 または Windows 11
- **必須環境**: 特になし（Windowsに標準搭載されている PowerShell を利用します）
- **ブラウザ**: Google Chrome, Microsoft Edge などのモダンブラウザ

---

## セットアップ＆起動手順
1. 本システムのフォルダ（この `README.md` があるフォルダ）をお好きな場所に配置します。
2. フォルダ内にある **`start.bat`** をダブルクリックして実行します。
3. 黒い画面（コマンドプロンプト/PowerShell）が立ち上がり、続いて自動でブラウザが立ち上がります。
4. ブラウザ上にタスク管理画面が表示されれば起動完了です！

> **※ 注意**: 初回起動時等に Windows Defender ファイアウォールやセキュリティソフトの確認画面が出た場合は、「アクセスを許可する」を選択して通信を許可してください。

---

## 主な機能・特徴

- **階層型タスク管理**: 親タスクの中に子タスク（サブタスク）を作成でき、深さ無制限の階層構造でタスクを管理できます。
- **ドラッグ＆ドロップの並び替え**: タスクをドラッグして直感的に順番を入れ替えることができます（親は親同士、子は同じ親の兄弟間でのみドラッグ可能です）。
- **テンプレート機能**: 定型作業を「テンプレート」として登録・管理するための専用タブを用意。よく使うタスクを雛形として管理できます。
- **使いやすい担当者・期限設定**: 担当者は過去に入力した名前履歴からのドロップダウン選択、または直接入力が可能です。期限はカレンダー（GUI）から簡単に選択でき、過去の日付は選べないように制御されています。
- **完全日本語対応＆レスポンシブデザイン**: 分かりやすい日本語UIと、画面サイズに合わせて自動調整される見やすいデザイン（列の縦揃えなど）を採用しています。
- **マルチフィルター検索**: ステータス・優先度・期限（開始／終了の範囲指定）・担当者（「担当者なし」を含む）で、表示するタスクを絞り込めます。
- **My Tasks ビュー**: 自分が担当のタスクだけを抽出して表示する専用タブを用意しています。
- **アーカイブ**: 完了したタスクを一覧から隠して保管できます。「アーカイブ済みタスク」タブからいつでも参照・復帰が可能です。
- **ゴミ箱（論理削除）**: 削除したタスクはいったん「ゴミ箱」へ移動します。誤って親タスクごと消してしまっても、ゴミ箱から **復元** できます。不要になったら **「ゴミ箱を空にする」** で完全削除します。
- **アラーム／リマインダー**: 指定した日時に Windows のデスクトップ通知（右下のポップアップ）でお知らせします。繰り返しは **なし（単発）／日次／週次／月次** に対応。バックグラウンドの監視プロセス（`alarm_monitor.ps1`）がブラウザを閉じていても常駐して時刻を監視し、`start.bat` 実行時に自動で起動します。
- **ポモドーロタイマー**: 作業／休憩のサイクルを回せるポモドーロタイマーを内蔵しています。

## 設定の変更について (config.json)
システムと同じフォルダにある `config.json` をメモ帳などのテキストエディタで編集することで、システムの設定を変更できます。

```json
{
  "userName": "YOUR_NAME_HERE",
  "dataDirectoryPath": "./data",
  "port": 18080
}
```

### 各項目の説明
- **`userName`**
  あなたのユーザ名です。タスクを新規作成した際の「担当者」としてデフォルトで自動入力されます。
- **`dataDirectoryPath`**
  タスクデータ(JSONファイル)を保存する基本フォルダの場所です。（タスクは `data/` 、テンプレートは本フォルダと同階層の `templates/` に保存されます）
  - デフォルトは `./data` （システムと同じ階層にある data フォルダ）です。
  - 【応用】社内の共有ファイルサーバーなどを指定する場合は `"\\\\サーバー名\\共有フォルダ名\\tasks"` のように指定してください。(`\`マークはJSONの規則上、2つや4つ重ねて書く必要があります）
- **`port`**
  システムが裏側で通信に使用するポート番号です。会社の別のシステムなどと競合して起動しない場合（画面が真っ白などの不具合時）は、`8181` や `28080` など別の番号に変更してください。

## 基本的な使い方

### 1. タスクの作成
- 左側のサイドバーにある青い **「＋ 新規タスク」** ボタンから新しいタスク（親タスク）を作成できます。
- タイトル、詳細、状態、優先度、担当者、期限を設定して保存します（タイトルと担当者は必須項目です）。

### 2. サブタスク（子要素）の作成
- 作成したタスクの右側にある **「＋」アイコン** をクリックすると、そのタスクの子としてサブタスクを追加できます。
- サブタスク配下にさらにサブタスクを作ることも可能です。タスクの開閉は、タスク左端の「∨ / ＞」アイコンをクリックすることで切り替えられます。

### 3. タスクの並び替え
- 各タスクの左端にある **「≡」（ドラッグハンドル）アイコン** を掴んで上下に移動させると、表示の順番を自由に変更できます。

### 4. タスクの編集と削除
- タスク項目の右側にある **「ペン」アイコン** をクリックで内容の編集ができます。
- **「ゴミ箱」アイコン** でタスクを削除できます。
  - **【重要】** 親タスクをごみ箱から削除すると、その下にぶら下がっている子タスクもまとめてすべて削除されます。

### 5. テンプレートの管理
- サイドバーの **「テンプレート」** タブに切り替えることで、テンプレートの一覧画面が開きます。
- ここから「新規テンプレート」の作成や、既存のテンプレート内容の編集・削除が可能です。定型タスクの雛形としてご活用いただけます。

---

## システムの終了方法
利用が終わったら、ブラウザのタブを閉じるだけでなく、**バックグラウンドで起動していた黒い画面（PowerShell / コマンドプロンプト）の右上の「×」ボタンを押して閉じてください**。
これで裏で動いていたシステムが完全に停止します。
